# МИКРОМИР — учебный сайт о палочковидных бактериях и спирохетах

## Запуск
1. Распакуйте архив.
2. Откройте `index.html` в браузере.
3. Для шрифтов Google Fonts и анимаций AOS нужен интернет. Без интернета сайт тоже работает: блоки просто появляются без анимации, а шрифты заменяются системными.

## Файлы
- `index.html` — структура всех разделов.
- `style.css` — оформление и адаптивность.
- `script.js` — меню, полоса прогресса, анимации, копирование заметок и просмотр фото по клику.
- `images/` — все изображения сайта (сжаты и обработаны).

## Как заменить фото
Положите новое изображение в `images/` и поменяйте имя файла в `src="images/..."` в `index.html`. Подпись и `alt` рядом тоже стоит обновить. Фото с атрибутом `data-zoom` открываются крупнее по клику (есть стрелки и клавиши ← → Esc).

## Важно про изображения
- Схемы бактерий (`schema-*.svg`) нарисованы для наглядности, не в масштабе. Это не микрофотографии.
- На снимках `micro-01` … `micro-04` видны клетки растительной ткани. Если нужны настоящие микрофотографии бактерий, их можно взять из проверенных учебных источников и указать источник в подписи.
- Это учебный информационный сайт. Не используйте неизвестные микробиологические культуры для самостоятельных экспериментов.
